Servers were configured.
OS: Linux Ubuntu 22.04.5
CPU: 2 cores
RAM: 2GB
HDD: 20GB
IP: 192.168.1.185

Was configured:

- timezone: Asia/Krasnoyarsk
- firewall: iptables (all drop except 22 port and icmp)
